# دِقَّة — محاسبة صارمة تعمل بلا إنترنت

<div dir="rtl">

**دِقَّة** تطبيق محاسبة للمنشآت الصغيرة (فريق من 1 إلى ~20 مستخدماً) يعمل **كاملاً بلا إنترنت** على جهازك: أندرويد وويندوز — بصرامة القيد المزدوج التي يفرضها النظام لا بوعدها.

## لماذا دِقَّة؟

- **قيد مزدوج مفروض آلياً**: التوازن مُفحص مرتين (مدقق برمجي + مشغل قاعدة البيانات يرفض أي ترحيل غير متوازن)، فالقيد غير المتوازن مستحيل بنيوياً لا ممنوعاً تمنياً.
- **بلا إنترنت وبلا اشتراك وبلا بطاقة**: قاعدتك على جهازك، مشفرة ChaCha20-Poly1305 بمفتاح في خزنة الجهاز — لا خادم ولا حساب سحابي ولا دفعة شهرية.
- **عربية RTL من الأساس**: تفقيط، طباعة PDF عربية بمقاسي A4/A5، عملات وأسعار صرف، دفاتر ومطابقات بلغة المحاسب.
- **سرمة بلا تعقيد**: الجرد الدائم بالمتوسط المرجح، مطابقة الذمم بأعمارها، فروق الصرف المحققة قيداً آلياً عند السداد، إقفال سنوي كامل المعنى.
- **مفتوحة البنية للفحص**: بنية ثلاث طبقات (نواة محاسبية نقية / تخزين / واجهة) بحدود مفروضة باختبارات آلية، ونحو 1,600 حالة اختبار تحرس كل دفعة.

## التحميل

الحزم تُبنى آلياً بكل إصدار (APK أندرويد arm64 + مجلد ويندوز محمول) وتُرفع كأثرات (Artifacts) في [صفحة Actions](../../actions) — حمّل أحدث تشغيل أخضر لحزمة منصتك.

> ملاحظة: تحميل الأثرات من GitHub يتطلب حساباً مجانياً وتسجيل دخول.

## البدء السريع

1. ثبّت الحزمة وافتح التطبيق — أول تشغيل ينشئ مديراً بكلمة تفرض تغييرها عند أول دخول.
2. أدخل أرصدتك الافتتاحية — الافتتاحية تسبق أول حركة وتُؤرَّخ بتاريخ تفعيل فعلي.
3. سجّل عملياتك اليومية: فواتير بيع وشراء ومردوداتها، سندات قبض ودفع بمطابقة آلية للذمم بالأقدمية.
4. خذ نسخة احتياطية مشفرة من الإعدادات — واستعدها على أي جهاز (الاستعادة مختبرة بتطابق 100%).
5. التقارير اليومية والقوائم المالية (قائمة الدخل والميزانية العمومية) تُقرأ من المرحّل حصراً — لا أرقام مخزنة تتحلل.

## البنية والفحص

```
packages/
  domain/    # النواة المحاسبية النقية — بلا Flutter وبلا Drift
  storage/   # طبقة SQLite/Drift — ترحيلات v1..v37 وسجل أحداث ملحق فقط
  app/       # واجهة Flutter — أندرويد وويندوز بقشرة واحدة
```

- **CI حاكم**: كل دفعة تجتاز فحصاً أسلوبياً واختبارات الحزم الثلاث وبوابة فحص أسرار.
- **سجل قرارات مرقم**: كل ميزة ومهل تأخذ قراراً موثقاً (سلسلة D) وسجل عمل مفصل بكل جلسة (`worklog.md`).
- **توثيق المشروع** في `docs/diqqah-v2.03/` — الرؤية والمصطلحات ودليل الحسابات والنموذج والسيناريوهات وخطة الإصدار.
