## 1. ما نُفذ

| الطبقة | التفصيل |
|---|---|
| بطاقة الرئيسية | بطاقة «الفواتير» أولَ القائمة بأربعة أزرار ملونة (فاتورة بيع أخضر / فاتورة شراء برتقالي / مردود بيع أزرق / مردود شراء وردي — عرف المعاينة المعتمدة) يُحدد النوع **بالضغط لا بانتقاء من قائمة» — ولسان البطاقة «اختر النوع بالضغط — لا قائمة انتقاء» |
| النموذج المثبت | كل زر يفتح نموذج الفاتورة الموحد بنوعه **المثبت** — مبدّل «نوع الفاتورة» حُذف كلياً فلا تبديل جهة بعد كتابة الأسطر، ولافتة ملونة بنوع الدخول مكانه |
| الأرشيف | زر «سجل الفواتير» أدنى البطاقة يفتح الأرشيف الموحد بفلتر النوع (الطبقة الثانية قائمة — س-60/D-080) — وزر الأرشيف «فاتورة جديدة» صار ورقة أزرار الأنواع ذاتها فالعزل بكل المداخل |
| الصلاحية | البطاقة خلف صلاحية «الفواتير» ذاتها (نمط D-100) |
| زوال علة قديمة | علة س-113 (بقاء «العميل» بلون التحديد بعد تبديل الجهة) زالت بزوال التبديل ذاته — ووسم «المعبأ آلياً» وإعادة تعبئته زالا معه (كود ميت لا يُترك) |
| فاتورة «نقل» | موضعها موثق D-160: زر خامس بالبطاقة ونوع خامس بالجدول الموحد بتسلسله السنوي — لا شيء بُني لها الآن حتى كلمتها |

## 2. اعتماد الدفعات الأربع — مثبت بسجل المراجعة

كلمة المالك «اعتمد الدفعات الأربعة» تسجل بقسم س52 في سجل المراجعة اعتماداً لجولات الدفعات: **(14)** أعمار الذمم ودفتر اليومية وملاحظة التسليم، **(15)** ما قبل إغلاق م1، **(16)** تعقيم أسماء مشاركة PDF، **(17)** لفظ المالك الثماني — ولا يبقى على تلك البوابات ما انتظاره.

1. **تجربة b22**: بطاقة الفواتير بأزرارها الأربعة — وكل ما جاء بدفعات 14..17 (القسيمة بلسانها الجديد والشعار الصوري والرقم القابل للتعديل وأعمار الذمم ودفتر اليومية ومشاركة PDF المعقمة).
