## 2. بروتوكول استخدام الحزمة مع الذكاء الاصطناعي في جلسات البرمجة

1. **قبل أي ميزة**: أرفق وثيقة 07 (الالتزام المعماري) + الوثيقة ذات الصلة بالميزة (04/05/06).
2. **الإحالة بالأرقام**: صِف المطلوب بمرجعه ("نفّذ F-…") من وثيقة 04 — لا بكلام حر.
3. **أي اقتراح يخالف وثيقة 07 يُرفض فوراً** مهما بدا أذكى — ويُسأل المالك قبل أي استثناء، ويُوثَّق الاستثناء في وثيقة 07 بإصدار جديد قبل التنفيذ.
4. **لا جلسة برمجة تبني "ميزة إضافية" خارج المرحلة النشطة** المحددة في وثيقة 09.
5. كل جلسة تنتهي بسؤالين إلزاميين: هل مرّ كل حساب عبر المحرك؟ هل تخزين المبالغ/الكميات مطابق للقاعدة التنفيذية رقم 1 في وثيقة 07؟
